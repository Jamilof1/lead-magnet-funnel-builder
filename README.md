# Lead Magnet Funnel Builder

Turn an offer and audience into a seven-stage acquisition flow covering landing copy, qualification, confirmation, nurture, tracking, and handoff.

## What it proves

- Structured funnel and nurture-sequence generation
- Event recommendations at every stage
- Qualification and sales-handoff design
- Copy-ready plan plus optional BYO-key AI refinement

## Quick start

Requires Node.js 22.12 or newer.

```bash
git clone https://github.com/Jamilof1/lead-magnet-funnel-builder.git
cd lead-magnet-funnel-builder
npm install
npm run dev
```

The local builder works without a key. For optional AI refinement, copy `.env.example` to `.env`, add `AI_API_KEY`, and restart. The key stays on the local server.

## Commands

```bash
npm run dev
npm test
npm run build
npm start
```
